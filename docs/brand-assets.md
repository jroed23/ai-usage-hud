# Brand assets

| Provider | Asset | Status |
|---|---|---|
| Claude | `src/assets/providers/claude.svg` (Claude Code pixel mascot, recreated as SVG from an image supplied by the project owner) and the app/tray icon | Anthropic trademark. Bundled at the owner's request. |

**Before making the repository public or distributing builds**, verify Anthropic's brand/usage guidelines for the mark. If redistribution is not allowed, replace `claude.svg` and `assets/app-icon.png` with a generic icon (the `ProviderIcon` glyph fallback activates automatically when `brand.logo` is unset).

The app must never suggest endorsement: the README, About page and Welcome screen state that this is an independent project.
