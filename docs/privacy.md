# Privacy

Local first. The app has no account, no backend and **no network code at all**.

Never collected: prompts, replies, file contents, file paths, keystrokes, screen, passwords, tokens.

Stored locally: preferences (view mode, position, theme...) and the latest usage percentages from Claude Code. Telemetry, diagnostics and logs: none.

To remove everything: Disconnect in Settings, uninstall, delete `%APPDATA%\ai-usage-hud` and the app's store folder.
