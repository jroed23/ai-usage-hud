# Code of Conduct

We follow the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

- Be respectful and constructive; no harassment, discrimination or personal attacks.
- Assume good faith, give and accept feedback graciously.
- Maintainers may remove comments, commits or contributors that violate these rules.

Report problems privately to the maintainers through GitHub (see SECURITY.md for contact options).
